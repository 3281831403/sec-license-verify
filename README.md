离线授权文件换个机器还能用，到期后功能也一直没锁：机器指纹用字典遍历顺序拼接，同一机器得到不同指纹；指纹不含网卡与卷标识，换机器仍一致；签名校验在解析之后，篡改体已被读入；签名比较用普通等号；有效期只比对起始时间，过期授权可用；时钟偏移作用于整个有效期，偏移被放大；绑定校验只比较前缀，同型号机器通用；功能集合直接信任授权体，未注册功能也放行；策略校验不检查长期有效授权；批量校验复用指纹，后一个授权命中前一个授权的机器。lic/_impl.py 是核心，tests/test_verify.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
